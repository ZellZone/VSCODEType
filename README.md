# Type Practice

在 VS Code 裡練習打字：終端機練英文，編輯器練專案裡的 JavaScript 與 PHP。

狀態列右側提供兩個按鈕，點一下即可開始。

## Type — 英文打字

在專用 Terminal 中練習常見英文單字，風格接近 Monkeytype。

- 每局 25 個英文單字
- 正確字元綠色、錯誤字元紅色，即時標示
- 結束後顯示 WPM、準確率與錯誤數
- 也可從指令面板執行 **Type Practice: Start (English)**

**終端機操作**

| 按鍵 | 作用 |
|------|------|
| 一般字元 | 輸入（錯字仍會前進並標紅） |
| Backspace | 回退 |
| Ctrl+R | 重開一局 |
| Enter（打完後） | 再來一局 |
| Esc | 結束並關閉 |

## Code — 程式碼打字

從目前工作區隨機挑選一篇 `.js`、`.jsx` 或 `.php`，在編輯器中逐行練習。

- 灰色斜體提示當前行內容
- 打字時即時標色：正確為綠、錯誤為紅
- 按 Enter 鎖定該行，接著出現下一行
- 整篇打完後顯示 WPM 與準確率
- 練習頁面會關閉自動完成與建議，避免擋住提示
- 也可從指令面板執行 **Type Practice: Code**

請先開啟含有 JavaScript 或 PHP 檔案的資料夾，再開始練習。

## 統計

- **WPM**：`(正確字元數 / 5) / 分鐘`（第一個有效按鍵才開始計時）
- **準確率**：`正確鍵擊 / 總鍵擊`
